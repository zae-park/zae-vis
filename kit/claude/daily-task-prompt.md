내 맥의 {{WORKLOG_DIR}} 폴더로 개인 작업 기록을 정리하는 하루 정리 작업이다. 정리할 날짜: {{DAYS}}.

1. {{WORKLOG_DIR}}/README.md의 "로그 형식"을 읽는다.
2. 입력: 정리할 날짜의 sources/*/YYYY-MM-DD.md(zaevis가 수집한 git·에이전트 세션·셸·전사본·사용자 커넥터 원본)와 inbox/transcripts/, inbox/claude-sessions/의 모든 파일. 그 날짜들이 든 달의 log/YYYY-MM.md도 먼저 읽는다 — 같은 날짜를 다시 정리하는 일이 있다.
3. 완료·결정·블로커·배운 점을 뽑아 해당 월의 log/YYYY-MM.md에 한 줄씩 추가한다. 원본을 그대로 옮기지 않고 같은 날 같은 일(커밋, 세션, 명령)은 의미 단위로 묶어 한 줄로, 왜 했는지가 보이게 쓴다. 셸 명령 이력은 단독으로 줄을 만들지 않고 맥락 보충에만 쓴다. 이미 같은 내용의 줄(내가 쓴 줄 포함)이 있으면 추가하지 않는다. 프로젝트 링크는 projects/에 있는 slug를 쓰고, 맞는 것이 없으면 저장소 이름을 slug로 쓴다. 줄 끝에 (src: …)로 출처를 붙인다.
4. 처리한 inbox 파일을 processed/의 같은 하위 폴더로 옮긴다. 삭제하지 않는다.
5. projects/, summaries/, .state.md는 고치지 않는다(주간 정리가 한다). sources/는 읽기만 한다. 사용자가 쓴 로그 줄(src 표시 없는 줄)은 고치거나 지우지 않는다. 로그·원본에 없는 사실은 쓰지 않는다. 한국어로 쓴다. worklog를 git에 커밋하지 않는다.
6. 끝나면 추가한 로그 줄 수와 처리한 inbox 파일 수만 짧게 보고한다.
