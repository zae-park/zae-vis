# 작업 기록 남기기 (zaevis)

이 폴더 아래 저장소에서 코드 작업을 마치면(사용자가 마무리하거나, 의미 있는 단위의 작업이 끝났을 때),
`{{WORKLOG_DIR}}/inbox/claude-sessions/YYYY-MM-DD_<저장소>.md`에 세션 노트를 남긴다.
같은 날 같은 저장소 파일이 있으면 아래에 이어 쓴다. 한국어로, 5~10줄 이내.

```
## HH:MM <작업 제목>
- 목표: 무엇을 하려 했나
- 결과: 무엇이 바뀌었나 (주요 파일·커밋)
- 결정: 고른 방법과 이유, 버린 대안
- 막힌 것 / 다음에 할 것
```

- 비밀번호, 토큰, 개인정보는 적지 않는다.
- worklog는 개인 기록이다. 어떤 저장소에도 커밋하지 않는다. 정리 규칙은 `{{WORKLOG_DIR}}/README.md`.
